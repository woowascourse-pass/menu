# 미션 - 점심 메뉴 추천
---

## 입력

---

### ☑️ 코치 이름 입력 뷰

```text
코치의 이름을 입력해 주세요. (, 로 구분)
토미,제임스,포코
```

---

### ☑️ 코치 못먹는 메뉴 입력 뷰

```text
토미(이)가 못 먹는 메뉴를 입력해 주세요.
우동,스시

```

---

## 출력

---

### ☑️ 서비스 시작 문구 출력 뷰

```text
점심 메뉴 추천을 시작합니다.
```

---

### ☑️ 메뉴 추천 결과 출력 뷰

```text
메뉴 추천 결과입니다.
[ 구분 | 월요일 | 화요일 | 수요일 | 목요일 | 금요일 ]
[ 카테고리 | 한식 | 한식 | 일식 | 중식 | 아시안 ]
[ 토미 | 쌈밥 | 김치찌개 | 미소시루 | 짜장면 | 팟타이 ]
[ 제임스 | 된장찌개 | 비빔밥 | 가츠동 | 토마토 달걀볶음 | 파인애플 볶음밥 ]
[ 포코 | 된장찌개 | 불고기 | 하이라이스 | 탕수육 | 나시고렝 ]

추천을 완료했습니다.
```

---

## 핵심 기능

---

### ☑️ 코치 이름 입력 기능

- 코치들의 이름을 입력한다.
- 코치의 이름은 최소 2글자, 최대 4글자이다.
- 입력값의 공백은 모두 제거한다.

### ⚠️ 기능 예외 사항

- 입력값이 공백만 있다면 예외를 발생 시켜야 한다.
- 코치의 이름이 2글자 미만, 4글자 초과면 예외를 발생 시켜야 한다.

---

### ☑️ 코치 못먹는 메뉴 입력 기능

- 코치들이 못먹는 메뉴를 입력한다.
- 못먹는 메뉴는 최소 0개, 최대 2개이다.
- 입력값의 공백은 모두 제거한다.
- 입력값이 공백이라면 메뉴를 0개 선택한 것이다.

### ⚠️ 기능 예외 사항

- 존재하지 않는 메뉴를 입력하면 예외를 발생 시켜야 한다.
- 못먹는 메뉴를 2개 초과하여 입력하면 예외를 발생 시켜야 한다.

---

### ☑️ 카테고리 및 메뉴 조회 기능

- 카테고리를 기반으로 메뉴 리스트를 조회한다.

---

### ☑️ 메뉴 추천 기능

- 월요일에 추천할 카테고리를 무작위로 정한다.
- 각 코치가 월요일에 먹을 메뉴를 추천한다.
- 화, 수, 목, 금요일ㄹ에 대해 위의 과정을 반복한다.
- 각 코치에게 한 주에 중복되지 않는 메뉴를 추천해야 한다.
- 코치가 먹지 못하는 메뉴를 추천하면 안된다.
- 한 주에 같은 카테고리는 최대 2회까지만 고를 수 있다.
