## 구현할 기능 목록

---

### 입력

- [X] 메뉴 추천을 받을 코치 이름 입력 받기  
  ⇒ `,` : 구분자  
  ⇒ 이름은 최소 2글자, 최대 4글자!!!!!  
  ⇒ 코치는 최소 2명, 최대 5명까지 가능
- [X] 입력 받은 각 코치에 대해서 각 코치가 못먹는 메뉴 입력  
  ⇒ 먹지 못하는 메뉴는 최소 0개 ~ 2개  
  ⇒ 0개면 빈칸
---
### 출력

- [X] 서비스 시작  
  ⇒ `점심 메뉴 추천을 시작합니다.`
- [X] 서비스 종료  
  ⇒ `메뉴 추천 결과입니다.`  
  ⇒ `[결과 보여주기]`  
  ⇒ `추천을 완료했습니다.`

---
### 메뉴 추천 방식

1. 월요일에 추천할 카테고리 무작위로 정하기!!  
   ⇒ [`camp.nextstep.edu.missionutils`](https://github.com/woowacourse-projects/mission-utils)에서
   제공하는 `Randoms.pickNumberInRange()`에서 생성해 준 값을 이용하여 정해야 한다.  
   ⇒ 일주일에 같은 카테고리는 최대 2번까지만 가능  
   ⇒ 카테고리를 각 코치가 아닌 모든 코치가 공유해서 사용
2. 추천할 메뉴는 정해진 카테고리에 있는
   메뉴를 [`camp.nextstep.edu.missionutils`](https://github.com/woowacourse-projects/mission-utils)에서
   제공하는 `Randoms.shuffle()`을 통해 임의의 순서로 섞은 후, `첫 번째 값`을 사용.    카테고리에 포함되는 메뉴 목록을 `List<String>` 형태로 준비한다.  
   ⇒ 코치 중 1명이라도 못 먹는 음식이 있으면 다시 뽑기!!!  
   ⇒ 각 코치들의 음식은 한주에 중복될 수 없다.
---
### 예외 처리

- [X] 코치 이름 길이가 최소 2글자, 최대 4글자를 벗어난 경우   
  ⇒ "[ERROR] 이름의 길이는 2글자 이상 4글자 이하여야 합니다."
- [X] 코치 명수가 2명이상 5명 이하를 벗어난 경우   
  ⇒ "[ERROR] 코치는 최소 2명이상 5명 이하만 가능합니다."
- [X] 못 먹는 음식을 0개 ~ 2개로 선택하지 않는 경우  
  ⇒ "[ERROR] 못 먹는 음식은 0개 ~ 2개까지만 선택 가능합니다."
- [X] 못 먹는 음식을 존재하지 않는 음식으로 입력했을 때  
  ⇒ "[ERROR] 존재하지 않는 음식입니다."
